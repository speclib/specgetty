## REMOVED Requirements

### Requirement: Archive tab lists archived changes with artifacts
**Reason**: The archive tab is removed. Archived changes are shown in the single
change list, selected by the open/archived/both filter defined in
`change-list-view`.

### Requirement: Archive tab shows artifact sub-tabs
**Reason**: Archived changes open at their own level through the same drill-down as active
changes, so a separate set of sub-tab requirements is no longer needed.

### Requirement: Archive tab navigation
**Reason**: There is one list with one cursor. Navigation is covered by the
change list navigation requirement in `changes-tab`.
