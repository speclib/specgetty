## Context

See proposal.md. The dial is a mechanical face with a driven hand, in a housing
that is already sealed against salt. Anything added has to live inside that
seal or outside the housing altogether.

## Goals / Non-Goals

Goals: the dial is readable at any hour without anyone doing anything.

Non-Goals: lighting the quay. A display of the time. Any change to what the
dial shows, which is the one thing about it nobody has complained about.

## Decisions

### Lit from behind, not from in front

A lamp in front of the face throws the hand's shadow across the marks it is
pointing between, which is the one part of the dial that has to stay readable.
Behind the face the hand is a silhouette, which is what it already is at dusk,
so the dial reads the same way in the dark as it does in falling light.

### The light is a property of the hour

A switch is a thing to forget. A sensor reading the ambient light is a thing to
clean twice a year, which the housing already asks for.

## Risks / Trade-offs

- Light spill onto the water, which the harbour has rules about. → Dim enough to
  read a silhouette by is far below them, and the housing already shades upward.
